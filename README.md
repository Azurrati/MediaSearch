# MediaSearch
MediaSearch is a command-line library that is used to search for text within media files such as image, video, or audio.

## Installation
Clone the repository
```
git clone https://github.com/Azurrati/MediaSearch
```

To start the project run this command with the required file path
```
python -m MediaSearch_project (path)
```

## Usage
For a list of commands run
```
python -m MediaSearch_project -h
```
or
```
python -m MediaSearch_project -help
```
